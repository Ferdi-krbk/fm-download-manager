# Bundled interface fonts

The application and extension bundle the unchanged static Inter Regular, Medium
and SemiBold TTFs from the official Inter 4.1 distribution. They do not require
installing a Windows font or reaching a font CDN at runtime.

- Project: https://github.com/rsms/inter
- Release: https://github.com/rsms/inter/releases/tag/v4.1
- Archive: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
- Archive SHA-256: `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`
- Archive paths: `extras/ttf/Inter-Regular.ttf`, `extras/ttf/Inter-Medium.ttf`, `extras/ttf/Inter-SemiBold.ttf`.
- License: SIL Open Font License 1.1. The upstream `LICENSE.txt` is distributed in
  both `src/McDm.App/Resources/Fonts/` and `extension/fonts/`.

The `fm.` brand artwork remains outlined; it does not depend on an installed font.
