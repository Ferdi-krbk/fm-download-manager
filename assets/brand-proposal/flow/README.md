# FM Flow identity proposal

Review assets for the proposed `fm.` identity. These files have not replaced the
shipping application or browser-extension branding.

- `wordmark-dark.svg` / `.png`: transparent wordmark for dark surfaces.
- `wordmark-light.svg` / `.png`: transparent wordmark for light surfaces.
- `wordmark-mono.svg` / `.png`: monochrome version.
- `app-icon.svg` / `.png` / `.ico`: application icon; ICO contains 16–256 px sizes.

The SVG lettering is outlined and does not require a font to be installed.
The exported accent is the violet reference. The proposed interface recolors the
dot to match the user's selected accent, with readable tones for light/dark mode.
The full wordmark stays recognizable without the accent color.
